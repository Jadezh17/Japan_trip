# Kyushu Trip Planner · 26 Mar – 10 Apr 2027

An interactive, single-page planner for a 14-night Kyushu road trip from Fukuoka to Sakurajima, with a day-by-day itinerary, map, things to do, and restaurant and hotel shortlists.

The first time you open the site on a device it asks for the trip's invite code (or you can open the invite link). Enter it once and every change — shortlists, booking status, itinerary adds, photos — saves to a shared Supabase database, so everyone on the trip sees the same plan. Choose "Just look around" to browse a copy whose changes stay in your own browser.
