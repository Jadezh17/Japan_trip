# Kyushu Trip Planner · 26 Mar – 10 Apr 2027

An interactive, single-page planner for a 14-night Kyushu road trip from Fukuoka to Sakurajima, with a day-by-day itinerary, map, things to do, and restaurant and hotel shortlists.

Open `index.html` in any browser. Everything is self-contained (map, data and photos are embedded). Shortlists and itinerary additions save in your own browser.

Photos marked "Wikimedia Commons" are used under their listed licences; see each place's photo credit.
